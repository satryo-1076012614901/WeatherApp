# Project WeatherApp
`Tugas AFL2 Mata Kuliah Visual Programing`
## About
Aplikasi cuaca yang mengambil data dari OpenWeather One Call API 3.0
## Sitemap
* Dashboard : Menampilkan List Card 5 kota (default)
* Detail City : Menampilkan data dari OpenWeather (current, hourly, daily)
* Add New City : Menambahkan kota baru ke dalam list dengan cara menginput nama kota, dan mencarinya pada OpenWeather
